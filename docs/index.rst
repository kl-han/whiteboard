Whiteboard developer documentation
==================================

Whiteboard is an open-source desktop app where humans and coding agents
architect software together in a shared workspace. This documentation is for
people who build, run, verify, or extend the Whiteboard repository.

.. note::

   The product is named **Whiteboard**, but most package names, directories
   and internal identifiers still say ``review`` (for example
   ``@dev.fast/review`` and ``apps/review-desktop``). See
   :doc:`src/architecture/descriptive_language`.
